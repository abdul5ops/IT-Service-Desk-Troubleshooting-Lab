# IT Service Desk Troubleshooting Lab

A hands-on portfolio project simulating real-world IT Service Desk operations. This lab demonstrates my troubleshooting skills, ITSM knowledge, and automation abilities for entry-level IT Support / Service Desk roles.

## What This Project Demonstrates

- ITIL/ITSM Incident Lifecycle: Full ticket documentation from logging to resolution
- Windows & Microsoft 365 Troubleshooting: Common end-user issues and fixes
- Active Directory Basics: User account management, password resets
- Network Troubleshooting: DNS, DHCP, VPN, connectivity issues
- Hardware Support: Printer, laptop, monitor troubleshooting
- Automation: Bash and PowerShell scripts for common IT tasks
- Documentation: Knowledge base articles with screenshots

## Project Structure

| Folder | Purpose |
|--------|---------|
| `tickets/` | Simulated ServiceNow-style incident tickets with full lifecycle |
| `troubleshooting/` | Knowledge base guides for common IT issues |
| `scripts/` | Automation scripts for IT support tasks |
| `screenshots/` | Evidence screenshots for each ticket/guide |
