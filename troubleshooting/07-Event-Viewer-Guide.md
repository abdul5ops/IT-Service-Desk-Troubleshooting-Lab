# Event Viewer Troubleshooting Guide

## Purpose
Event Viewer records all system events — errors, warnings, and information. IT Support uses it to diagnose system issues.

## How to Access
1. Press Win + R, type: eventvwr.msc
2. Navigate to: Windows Logs → System
3. Filter by: Error / Warning

## Common Errors
- Event ID 41: Unexpected shutdown
- Event ID 7000: Service failed to start
- Event ID 1001: BugCheck (BSOD related)
